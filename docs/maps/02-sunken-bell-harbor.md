# 地图二《沉钟港》六大场景内容大纲

> 战役职责：展示记忆献祭如何制度化、商品化并影响普通人  
> 所属战役：[四地图战役整体框架](../CAMPAIGN_MAP_FRAMEWORK.md)  
> 建议游戏时长：70—100 分钟  
> 可与地图三《无名林海》交换游玩顺序

---

## 1. 核心体验承诺

玩家进入一座以记忆作为货币、债务和身份证明的潮港，在相互冲突的证词中追查灰烬塔的记忆来源，并决定港口应继续供应、公开改革、自治接管还是彻底终止征忆制度。

核心问题：

> 当记忆能够换取食物、身份和安全，“自愿出售”是否仍然意味着真正同意？

### 1.1 地图输入

- `towerOutcome`；
- 守忆人关系、剩余余烬与回声侵蚀；
- 灰烬塔取得的记忆证词；
- 是否已经完成无名林海；
- 是否掌握自然记忆循环和替代封印原理。

### 1.2 地图输出

- `harborOutcome`：维持监管、公开改革、工会自治、摧毁征忆网络；
- `publicSupport`：港口公众支持度；
- `testimonyCount`：可提交回声王庭的有效证词；
- `masterLedger`：中央征忆总账；
- 港口代表是否愿意进入回声王庭作证；
- 玩家与港务署、潮工会、记忆行商的关系。

## 2. 地图状态

| 状态 | 范围 | 作用 |
| --- | ---: | --- |
| 公众支持 | -2—2 | 决定群众是否相信玩家并参与最终行动 |
| 港务署关系 | -2—2 | 决定合法路线、档案权限和官方协助 |
| 潮工会关系 | -2—2 | 决定证人保护、地下路线和自治结局 |
| 行商关系 | -2—2 | 决定交易情报、伪造身份和资本派结局 |
| 港口紧张度 | 0—3 | 越高越容易出现冲突、封锁和记忆失控 |
| 总账证据 | 0—3 | 达到 2 可证明制度性强征，达到 3 可追溯回声王庭 |
| 回流记忆 | 0—3 | 仅灰烬塔释放记忆时启用，表示城市身份冲突强度 |

### 2.1 状态反馈

- 公众支持通过街道回应、证人是否出现和群众是否保护玩家呈现；
- 三个阵营关系通过人物行为呈现，不直接显示数值；
- 紧张度通过钟声频率、巡逻密度、争执和潮水颜色呈现；
- 总账证据与有效证词必须作为明确线索显示；
- 回流记忆只代表社会混乱程度，不判定哪一份记忆“更真实”。

## 4. 场景一：潮关验忆所

### 4.1 场景职责

- 建立“记忆是身份证明”的港口规则；
- 根据灰烬塔结局改变玩家入境身份；
- 引入港务署验忆官黎珀；
- 让玩家第一次决定是否交出私人记忆。

### 4.2 场景内容

所有入港者都必须在潮关铜钟下提供一段可核验记忆。钟声会与港口档案共振，判断来访者是否使用他人身份。玩家的灰烬塔记录已经先于本人抵达，却因区域结局不同而呈现不同标签。

### 4.3 不可变事实

- 铜钟只能判断记忆是否与档案一致，不能判断证词是否道德或完整；
- 玩家不必交出私人背景才能进入港口；
- 灰烬塔征集船册是合法入境证据之一；
- 验忆官知道制度存在漏洞，但没有权限公开推翻它。

### 4.4 推进方法

#### 方法 A：使用灰烬塔船册合法入境

- 条件：持有征集船册；
- 结果：港务署关系 +1；
- 代价：玩家行踪被登记；
- 类型：`progress`。

#### 方法 B：借潮工队伍混入

- 结果：不留下官方记录；
- 代价：潮工会欠情或要求玩家帮助一名失忆工人；
- 类型：`costly_success`。

#### 方法 C：让余烬灯验证经历

让灯火重现灰烬塔已确认事实，而非交出私人记忆。

- 条件：灯火至少 1；
- 结果：揭示验忆制度并非只能依靠献忆；
- 状态：公众支持 +1，港务署关系可能 -1；
- 类型：`progress`。

### 4.5 失败推进

验证失败不会遣返玩家。验忆钟会将玩家标记为“身份待定”，迫使其在失名集市寻找担保人，同时让玩家发现有人正在批量出售伪造身份记忆。

### 4.6 情绪节奏

```text
抵达新奇 → 被制度审视 → 身份不安 → 获得行动入口
```

## 5. 场景二：失名集市

### 5.1 场景职责

- 展示记忆交易如何融入日常生活；
- 引入记忆行商萨弥与潮工代表岑浪；
- 提供总账证据的第一条来源；
- 让玩家在便利与剥削之间作出第一次港口选择。

### 5.2 场景内容

集市摊位出售“七岁夏天”“一门手艺”“一次无痛告别”等封装记忆。部分交易真实自愿，另一些来自债务抵押或身份盗取。市场中央的失名者只能依靠刻在手臂上的临时编号生活。

### 5.3 不可变事实

- 并非所有记忆交易都来自强迫；
- 行商不能制造记忆，只能复制、剪裁、转移或伪造归属；
- 复制品会逐渐失真，不能作为最终法庭的唯一证据；
- 一份灰烬塔采购印记隐藏在市场交易票据中。

### 5.4 推进方法

#### 方法 A：追查采购印记

- 结果：获得总账证据 1；
- 后果：引起行商注意；
- 类型：`progress`。

#### 方法 B：帮助失名者核验身份

- 条件：使用灰烬塔证词、验忆钟漏洞或自然循环知识；
- 结果：公众支持 +1，获得潮工会担保；
- 类型：`progress`。

#### 方法 C：与行商交换情报

- 结果：直接得到征忆库入口位置；
- 代价：交出一项非关键线索副本，或承诺保护部分合法交易；
- 类型：`costly_success`。

### 5.5 失败推进

若玩家公开指控但证据不足，商贩会销毁表面票据。销毁产生的灰烬暴露隐藏水印，使玩家仍获得采购船编号，但行商关系 -1、港口紧张度 +1。

### 5.6 情绪节奏

```text
市井活力 → 奇异诱惑 → 伦理不适 → 明确怀疑
```

## 6. 场景三：潮痕街区

### 6.1 场景职责

- 让制度代价具体化；
- 处理灰烬塔释放记忆造成的回流差异；
- 取得可被回声王庭承认的第一份活人证词；
- 建立公众支持或提高社会紧张。

### 6.2 场景内容

潮痕街区居住着码头工、失名者和记忆回流者。一名工人突然记起自己曾拥有另一身份，而另一户家庭坚持那段记忆属于已经死亡的亲人。巡逻队准备以“记忆污染”为由封锁街区。

### 6.3 不可变事实

- 回流记忆可能真实，却不自动赋予财产和身份所有权；
- 两个相互冲突的人都可能在诚实描述自己的体验；
- 港务署封锁只能压制冲突，不能判定记忆归属；
- 至少有一名居民能证明征忆契约是在饥荒压力下签署的。

### 6.4 推进方法

#### 方法 A：建立多源核验

对照身体习惯、旧物、第三方证词和港口记录，不依赖单段记忆判定身份。

- 结果：取得有效证词；
- 状态：公众支持 +1，港口紧张度 -1；
- 类型：`progress`。

#### 方法 B：组织临时共同身份

承认双方都携带同一记忆的不同部分，先保护生活权利，再延后财产判定。

- 结果：避免即时冲突；
- 代价：港务署关系 -1；
- 类型：`costly_success`。

#### 方法 C：协助巡逻队封锁

- 结果：快速恢复表面秩序；
- 状态：港务署关系 +1、公众支持 -1；
- 持续影响：部分证人不愿公开作证；
- 类型：`costly_success`。

### 6.5 失败推进

若玩家武断宣布某一方为“真正所有者”，冲突会升级但不会锁死主线。受损旧物暴露契约编号，使玩家获得征忆库路径，同时公众支持 -1、紧张度 +1。

### 6.6 情绪节奏

```text
生活气息 → 身份冲突 → 同情与愤怒 → 艰难暂缓
```

## 7. 场景四：沉钟议事厅

### 7.1 场景职责

- 汇总前三场取得的事实；
- 让港务署、潮工会和记忆行商公开提出利益立场；
- 决定进入海底征忆库的方式；
- 让玩家选择暂时盟友而非永久阵营。

### 7.2 场景内容

半沉入海水的议事厅中，三方围绕征忆制度展开听证。每次潮水撞钟，发言者刚说过的一个词会从所有听众记忆中短暂消失，使记录本身也不可靠。

### 7.3 不可变事实

- 三个阵营都拥有部分真实事实和明确利益；
- 港务署维持秩序但隐瞒强征规模；
- 潮工会保护受害者但内部存在报复派；
- 行商掌握流通网络，但从制度中持续获利；
- 海底征忆库保存着无法靠公开票据替代的中央总账。

### 7.4 推进方法

#### 方法 A：公开证据促成授权调查

- 条件：总账证据至少 1、公众支持不低于 0；
- 结果：获得合法进入征忆库的权限；
- 代价：港务署可提前转移部分敏感档案；
- 类型：`progress`。

#### 方法 B：与潮工会合作潜入

- 结果：得到旧排水道路线；
- 代价：承诺优先保护证人而非资产；
- 类型：`costly_success`。

#### 方法 C：与行商合作调包钥印

- 结果：获得最短路线；
- 代价：行商要求销毁一部分能定罪合法商户的复制记录；
- 类型：`costly_success`。

### 7.5 失败推进

若听证会失控，议事厅会提前进入封锁状态。三方代表分别逃往不同出口，玩家必须选择跟随其中一方；被放弃的阵营关系 -1，但其掉落物仍提供征忆库入口。

### 7.6 情绪节奏

```text
暂时秩序 → 立场交锋 → 证据受质疑 → 选择盟友
```

## 8. 场景五：海底征忆库

### 8.1 场景职责

- 形成地图动作高潮；
- 取得中央征忆总账；
- 揭露回声王庭主动扩大记忆需求；
- 检验玩家是否愿意为了证据牺牲仍可归还的记忆。

### 8.2 场景内容

征忆库位于港口水线以下，数以千计的记忆瓶悬在潮压机关中。中央总账同时记录捐献、抵债、强征和“无法追溯来源”的记忆。库房正在进水，玩家无法无代价保存所有内容。

### 8.3 不可变事实

- 总账原件可以证明回声王庭设定了逐年增加的征忆指标；
- 记忆瓶中的内容属于具体个人，不是普通能源；
- 玩家最多完整保住总账、证人记忆库、港务署运行档案中的两类；
- 余烬灯可以稳定记忆，但不能无限扩容。

### 8.4 推进方法

#### 方法 A：先保总账与证人记忆

- 结果：总账证据达到 3，证词数量增加；
- 代价：港口运行档案被水毁，短期秩序下降；
- 类型：`costly_success`。

#### 方法 B：先保总账与运行档案

- 结果：保留改革所需行政能力；
- 代价：部分可归还记忆永久散失，公众支持 -1；
- 类型：`costly_success`。

#### 方法 C：使用余烬灯临时稳定全部档案

- 条件：灯火至少 2；
- 结果：全部保存；
- 代价：灯火降至 0、回声侵蚀 +1；
- 类型：`costly_success`。

#### 方法 D：若已掌握自然封印原理

- 条件：先完成无名林海；
- 结果：利用自然回流暂存全部记忆；
- 代价：港口紧张度 +1，因回流引发短期记忆风暴；
- 类型：`progress`。

### 8.5 失败推进

若玩家触发潮压崩溃，会被迫乘档案浮柜逃出。系统自动保留玩家此前明确优先保护的一类内容，并让另一类内容以碎片形式散入港口，改变最终场景而非直接重开。

### 8.6 情绪节奏

```text
潜入压迫 → 时间紧迫 → 规模震撼 → 无法全救的痛苦
```

## 9. 场景六：万钟码头

### 9.1 场景职责

- 将证据、阵营关系和公众支持转化为区域结局；
- 决定谁管理港口记忆；
- 选出是否进入回声王庭作证的代表；
- 完成从个人证词到公共决策的主题收束。

### 9.2 场景内容

总账公开前夕，万钟码头聚集了失名者、港务官、潮工和行商。中央征忆船即将靠岸取走本季度记忆，玩家必须决定如何处理总账、仓库和征忆船。

### 9.3 区域结局 A：维持并加强监管

- 条件：港务署关系不低于 1；
- 结果：暂停强征，保留自愿交易和中央供应；
- 优势：港口秩序稳定、行政支持高；
- 代价：制度根基仍然存在；
- 战役输出：`harborOutcome = regulated`。

### 9.4 区域结局 B：公开改革

- 条件：总账证据至少 2、公众支持至少 1；
- 结果：公开全部契约，建立撤回同意和记忆归还制度；
- 优势：获得公开证人和广泛支持；
- 代价：港口短期陷入身份与债务重算；
- 战役输出：`harborOutcome = reformed`。

### 9.5 区域结局 C：潮工自治

- 条件：潮工会关系至少 1；
- 结果：工会接管征忆库，拒绝中央配额；
- 优势：证人受到保护，中央供应立即中止；
- 代价：可能形成新的地方垄断；
- 战役输出：`harborOutcome = autonomous`。

### 9.6 区域结局 D：摧毁征忆网络

- 条件：玩家明确选择且已预警后果；
- 结果：征忆船、总钟与交易印记全部失效；
- 优势：中央无法继续从港口抽取记忆；
- 代价：依赖记忆档案维持身份的人面临长期混乱；
- 战役输出：`harborOutcome = destroyed`。

### 9.7 失败推进

若总账证据不足或公众支持过低，玩家无法推动公开改革，但仍可选择监管、自治或摧毁。系统不得将“没有最佳结局”处理为主线失败。

### 9.8 情绪节奏

```text
群众聚集 → 事实公开 → 阵营对峙 → 集体决定 → 喧闹后的潮声
```

## 10. 场景持续后果

| 早期行动 | 后续影响 |
| --- | --- |
| 合法登记入港 | 更易取得议事厅授权，但行踪透明 |
| 帮助失名者 | 提高公众支持并获得证人保护 |
| 与行商交易 | 快速取得路线，但改革信誉可能受损 |
| 支持街区封锁 | 提高官方关系，降低证人意愿 |
| 选择特定阵营潜入 | 改变征忆库中优先保护目标 |
| 保存证人记忆 | 强化回声王庭法理证据 |
| 保存运行档案 | 强化改革后的执行能力 |

## 11. AI 叙事边界

AI 可以描写：

- 记忆交易带来的感官错位；
- 不同阵营对同一事实的利益解释；
- 回流记忆造成的真实困惑；
- 公众对玩家已确认行动的反应。

AI 不得：

- 判定某段回流记忆天然拥有身份或财产权；
- 把贫困下签署的契约自动描述为完全自愿；
- 让任一阵营无条件代表正义或邪恶；
- 擅自增加总账证据、公众支持或阵营关系；
- 创造玩家未取得的自然封印知识；
- 让一次演讲替代结构化结局条件。
