# 地图三《无名林海》六大场景内容大纲

> 战役职责：揭示余烬、黑焰与自然遗忘循环的起源  
> 所属战役：[四地图战役整体框架](../CAMPAIGN_MAP_FRAMEWORK.md)  
> 建议游戏时长：70—100 分钟  
> 可与地图二《沉钟港》交换游玩顺序

---

## 1. 核心体验承诺

玩家进入一片会吸收名字、保存痕迹并归还记忆的古老林海，通过克制采集、观察自然规律和修复被人为切断的根脉，理解“记住一切”并不等同于尊重生命。

核心问题：

> 如果遗忘本身是生命循环的一部分，强迫所有记忆永远存在，是否也是一种伤害？

### 1.1 地图输入

- `towerOutcome`；
- 剩余余烬灯火与回声侵蚀；
- 是否保存过记忆回声；
- 是否已经完成沉钟港；
- 港口证词、公众支持与总账证据；
- 玩家此前履行或违背的誓言。

### 1.2 地图输出

- `forestOutcome`：恢复循环、受控共生、封闭林海或夺取根火；
- `naturalSealKnowledge`：不依赖记忆献祭的封印原理；
- `forestRecognition`：林海对玩家的认可；
- `rootCovenant`：林海是否愿意协助回声王庭改革；
- 一枚通向王庭自然根路的“年轮印”；
- 余烬灯最终形态。

## 2. 地图状态

| 状态 | 范围 | 作用 |
| --- | ---: | --- |
| 林海认可 | -2—2 | 决定林中存在是否协助玩家及最终契约 |
| 循环平衡 | -2—2 | 代表记忆归还、消散与保留之间是否失衡 |
| 根脉污染 | 0—3 | 越高，黑根扩散越快，安全路线越少 |
| 年轮印记 | 0—3 | 三枚印记共同构成自然封印知识 |
| 暂借名字 | 无／已借／已归还 | 代表玩家是否接受林海通行规则 |
| 保存回声 | 0—3 | 玩家携带且尚未决定归宿的记忆人格 |

### 2.1 状态反馈

- 林海认可通过道路是否主动显现、动物是否靠近和树语态度呈现；
- 循环平衡通过落叶方向、菌光颜色和回声是否能够停止呈现；
- 根脉污染通过黑色树脂、逆向生长和无源人声呈现；
- 年轮印记作为明确线索显示；
- “暂借名字”不要求玩家提供真实姓名或角色背景。

## 4. 场景一：遗名边界

### 4.1 场景职责

- 建立林海的命名规则；
- 检查玩家如何对待身份与控制；
- 根据沉钟港完成情况改变入林论据；
- 引入引路存在“枝尾”。

### 4.2 场景内容

林海外缘的路标正在失去文字。越接近树线，物品名称越难被说出口，但其用途和形态没有消失。一只尾部生着细枝的白兽要求玩家暂时放下一个“通行称谓”，避免林海把名字误当作应被永久保存的记忆。

### 4.3 不可变事实

- 林海不会偷走玩家人格或背景；
- 暂借名字只影响林内称呼，不删除玩家状态；
- 玩家可以使用自选代号、物件称呼或拒绝命名；
- 强行刻名会提高根脉污染，因为固定命名阻碍自然流动。

### 4.4 推进方法

#### 方法 A：接受暂借称谓

- 结果：获得林内代号，枝尾成为引路者；
- 状态：林海认可 +1、暂借名字 = 已借；
- 类型：`progress`。

#### 方法 B：以行为代替名字

通过点灯、展示年轮线索或帮助受困生物证明来意。

- 结果：保留原称呼并获准进入；
- 条件：拥有灰烬塔余烬线索或港口证词；
- 类型：`progress`。

#### 方法 C：强行刻下身份标记

- 结果：道路被固定并可通行；
- 代价：根脉污染 +1、林海认可 -1；
- 类型：`costly_success`。

### 4.5 失败推进

若玩家不断尝试宣称对林海的所有权，道路会把玩家送回同一棵树前。重复路径会显露人类测绘钉，提供黑根裂谷方向，但林海认可 -1。

### 4.6 情绪节奏

```text
寂静进入 → 语言失效 → 身份轻微动摇 → 找到新的沟通方式
```

## 5. 场景二：余烬菌庭

### 5.1 场景职责

- 揭示余烬灯并非人工燃料，而是林海共生体；
- 建立“使用资源”和“掠夺资源”的区别；
- 提供补充灯火的机会；
- 取得第一枚年轮印记。

### 5.2 场景内容

巨大倒木内部生长着温暖发光的余烬菌。菌群吸收已经完成归还的记忆残热，并将其转化为不会说话的灯火。人类采集架仍刺在倒木中，持续抽走尚未成熟的菌核。

### 5.3 不可变事实

- 成熟余烬不包含可识别人格或秘密；
- 未成熟菌核仍连接具体记忆，强取会造成伤害；
- 玩家可以补充灯火，但不能无代价无限采集；
- 第一枚年轮印记记录“记忆必须先被见证，再被放下”。

### 5.4 推进方法

#### 方法 A：清除采集架并等待成熟

- 结果：灯火 +2、林海认可 +1；
- 获得：年轮印记“见证”；
- 类型：`progress`。

#### 方法 B：使用灰烬塔灯芯引导成熟

- 结果：灯火补至上限；
- 代价：旧灯芯被永久改变，之后不能再封存活跃回声；
- 类型：`costly_success`。

#### 方法 C：强取未成熟菌核

- 结果：立即获得大量灯火；
- 代价：林海认可 -1、循环平衡 -1、保存回声 +1；
- 类型：`costly_success`。

### 5.5 失败推进

误触菌群会释放一段不完整回声。回声无法提供新秘密，却会重复“先听完”的请求。玩家只需完成倾听即可恢复菌庭稳定并取得印记，但灯火只增加 1。

### 5.6 情绪节奏

```text
柔光惊奇 → 资源诱惑 → 理解生命边界 → 克制满足或隐约亏欠
```

## 6. 场景三：忘川兽径

### 6.1 场景职责

- 让自然记忆循环成为可观察过程；
- 检验玩家对保存回声的态度；
- 取得第二枚年轮印记；
- 将地图节奏推入第一次动作高峰。

### 6.2 场景内容

一群负载记忆种子的迁徙兽正在穿越泛白河床。黑根猎影追逐它们，试图在种子归土前吞噬记忆。枝尾要求玩家保护迁徙，却提醒玩家不能替兽群决定所有种子都必须留下。

### 6.3 不可变事实

- 迁徙兽不是人类亡魂；
- 记忆种子只有一部分会萌发，其余会自然消散；
- 黑根猎影来自人类抽取装置造成的污染；
- 第二枚年轮印记记录“归还不等于永久保存”。

### 6.4 推进方法

#### 方法 A：利用环境引导迁徙

观察水痕、风向和根脉反应，为兽群打开安全路线。

- 结果：不消耗灯火；
- 状态：循环平衡 +1；
- 获得：年轮印记“归还”；
- 类型：`progress`。

#### 方法 B：使用灯火驱散猎影

- 结果：快速保护兽群；
- 代价：灯火 -1、塔系气息使林海认可不变；
- 类型：`costly_success`。

#### 方法 C：将猎影引向保存回声

玩家可以用一段自愿放下的保存回声吸引猎影，再让菌根分解污染。

- 条件：保存回声至少 1；
- 结果：保存回声 -1、根脉污染 -1；
- 代价：该回声永久消散；
- 类型：`costly_success`。

### 6.5 失败推进

若迁徙队伍被冲散，玩家仍会跟随一头受伤幼兽抵达年轮圣所。循环平衡 -1，但幼兽携带的种子提供第二枚印记，主线继续。

### 6.6 情绪节奏

```text
柔和观察 → 突发追逐 → 保护冲动 → 接受并非一切都能保存
```

## 7. 场景四：年轮圣所

### 7.1 场景职责

- 完整解释自然遗忘循环；
- 让玩家验证灰烬塔和沉钟港的制度假设；
- 提供动作高潮后的安静场景；
- 取得第三枚年轮印记和自然封印原理。

### 7.2 场景内容

圣所由一圈活树构成，每道年轮保存同一事件在不同生命中的痕迹。玩家可以同时看见一次离别如何被某人铭记、被另一人误解、又如何在几代后只剩下帮助植物迁徙的模糊习惯。

### 7.3 不可变事实

- 林海保存关系与影响，不保证永久保留完整叙事；
- 遗忘不会自动消除事实责任；
- 黑焰产生于“只抽取、不归还”的单向封存；
- 自然封印需要见证、归还和留白三部分共同成立；
- 港口证词可以证明社会需要见证，自然规律不能代替人的同意。

### 7.4 推进方法

#### 方法 A：组合三枚年轮印记

- 条件：已取得“见证”与“归还”；
- 结果：获得第三枚“留白”和 `naturalSealKnowledge = true`；
- 类型：`progress`。

#### 方法 B：用港口证词补足见证

- 条件：先完成沉钟港并保存有效证词；
- 结果：即使前场缺少一枚印记，也能理解完整原理；
- 代价：证词副本留在圣所，供林海认识人类处境；
- 类型：`progress`。

#### 方法 C：强行复制圣所全部年轮

- 结果：取得大量历史片段；
- 代价：回声侵蚀 +1、林海认可 -1；
- 限制：复制内容不能替代自然封印知识；
- 类型：`costly_success`。

### 7.5 失败推进

若玩家错误地把遗忘理解为销毁一切，圣所会展示被彻底切断关系后造成的黑根。玩家仍获得“留白”印记，但自然封印知识暂时不完整，需在黑根裂谷通过实际修复补全。

### 7.6 情绪节奏

```text
宏大敬畏 → 多重悲伤 → 理解消散 → 平静与责任
```

## 8. 场景五：黑根裂谷

### 8.1 场景职责

- 揭露建塔者如何截断林海根脉；
- 形成地图危险高潮；
- 将自然封印知识转化为可执行方法；
- 决定玩家是修复、控制还是继续抽取力量。

### 8.2 场景内容

裂谷底部仍运转着最早的余烬抽取机。管线一端连接林海母根，另一端通往回声王庭。黑色树脂沿逆向年轮扩散，猎影和被拒绝消散的回声聚集在机器周围。

### 8.3 不可变事实

- 抽取机是人为装置，不是林海自然器官；
- 直接摧毁机器会停止抽取，但可能让污染瞬间回流；
- 机器保存着通往回声王庭的根路坐标；
- 污染可以被分段归还、受控封存或强制转移，但不存在无代价清除。

### 8.4 推进方法

#### 方法 A：分段逆转抽取

- 条件：自然封印知识完整；
- 结果：根脉污染 -2、取得王庭坐标；
- 代价：玩家必须消耗一段时间保护脆弱回流，塔顶警觉可能上升；
- 类型：`progress`。

#### 方法 B：切断机器并承受回流

- 结果：抽取立即停止；
- 代价：回声侵蚀 +1、循环平衡 -1；
- 持续影响：母树最终决策更为困难；
- 类型：`costly_success`。

#### 方法 C：接管机器抽取根火

- 结果：余烬灯升级为高容量根火灯；
- 代价：林海认可 -2、根脉污染 +1；
- 持续影响：开放夺取型区域结局；
- 类型：`costly_success`。

#### 方法 D：借助港口集体证词稳定回流

- 条件：先完成沉钟港且公众支持至少 1；
- 结果：人类证词承担“见证”环节，降低修复代价；
- 状态：根脉污染 -2、林海认可 +1；
- 类型：`progress`。

### 8.5 失败推进

若抽取机失控，枝尾会牺牲自己的固定形态堵住一条管线。主线继续，玩家取得王庭坐标，但保存回声 +1、林海认可上限下降，最终场景必须处理枝尾留下的记忆种子。

### 8.6 情绪节奏

```text
发现伤口 → 理解人为责任 → 紧迫修复 → 承担不可避免的余波
```

## 9. 场景六：无名母树

### 9.1 场景职责

- 将循环平衡、林海认可与黑根处理方式转化为区域结局；
- 决定林海是否参与回声王庭改革；
- 决定余烬灯最终形态；
- 完成“记住与放下并不矛盾”的主题收束。

### 9.2 场景内容

母树没有单一人格，而以无数短暂声音共同表达林海意志。它要求玩家说明人类为何仍需要保存记忆，并决定是否再次允许人类使用余烬。

玩家的论据只能引用已经获得的事实、证词和实际行动。AI 不得让华丽说辞替代条件。

### 9.3 区域结局 A：恢复自然循环

- 条件：自然封印知识完整、循环平衡不低于 0；
- 结果：林海重新接纳被截断的记忆流；
- 优势：获得年轮印与稳定根路；
- 代价：部分保存回声选择自然消散；
- 战役输出：`forestOutcome = restored`。

### 9.4 区域结局 B：建立受控共生

- 条件：林海认可至少 1，并能证明人类存在有效同意机制；
- 结果：林海允许有限采集成熟余烬，人类负责见证和归还；
- 优势：获得林海盟友与替代封印支持；
- 代价：需要港口或未来机构持续监督；
- 战役输出：`forestOutcome = covenant`。

### 9.5 区域结局 C：封闭林海

- 条件：玩家主动选择或林海认可低于 0；
- 结果：母树封闭所有人类采集路径；
- 优势：林海免受继续掠夺；
- 代价：余烬供应中止，回声王庭改革难度上升；
- 战役输出：`forestOutcome = sealed`。

### 9.6 区域结局 D：夺取根火

- 条件：玩家已接管抽取机并明确选择；
- 结果：玩家取得强大根火灯和王庭路线；
- 优势：最终地图拥有高强度能源；
- 代价：林海拒绝合作，循环持续受损；
- 战役输出：`forestOutcome = harvested`。

### 9.7 名字归还

若玩家暂借了称谓，场景结尾必须提供归还机会。归还不改变角色身份，只代表玩家结束林内关系。主动归还会增加林海认可；强留称谓则成为一项可追溯承诺。

### 9.8 情绪节奏

```text
庄严会面 → 陈述人类需要 → 面对自身行为 → 契约、分离或掠夺 → 林声渐远
```

## 10. 场景持续后果

| 早期行动 | 后续影响 |
| --- | --- |
| 接受暂借称谓 | 更易获得引路与林海认可 |
| 强行刻名 | 路线明确，但污染和抵触上升 |
| 等待余烬成熟 | 保持循环并获得稳定灯火 |
| 强取菌核 | 获得更多资源，同时增加保存回声负担 |
| 保护迁徙兽 | 提高循环平衡并获得安全知识 |
| 放下一段保存回声 | 降低污染，但永久失去该回声 |
| 用证词稳定根脉 | 证明人类社会与自然规律可以合作 |
| 夺取根火 | 强化最终行动，关闭林海合作方案 |

## 11. AI 叙事边界

AI 可以描写：

- 名称短暂模糊但用途仍然清晰的感受；
- 林海通过多种非人信号回应玩家；
- 同一记忆如何在不同生命中留下不同影响；
- 玩家已确认选择造成的生态变化。

AI 不得：

- 擅自删除玩家身份、背景、物品或状态；
- 宣称所有遗忘都是善或所有保存都是恶；
- 让林海知道港口中未带入的具体秘密；
