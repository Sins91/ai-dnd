# 地图一《灰烬塔》六大场景内容大纲

> 文档性质：游戏内容与情绪节奏设计基准  
> 设计依据：[AI 文字冒险设计圣经](../../.agents/skills/design-ai-adventures/references/design-bible.md)  
> 所属战役：[四地图战役整体框架](../CAMPAIGN_MAP_FRAMEWORK.md)  
> 建议游戏时长：60—90 分钟  
> 核心模式：确定性规则裁定事实与后果，AI 负责理解玩家意图并演绎已批准结果

---

## 1. 核心体验承诺

玩家携带一盏有限燃烧的余烬灯进入灰烬塔，通过观察、交涉和承担代价，辨别真实记忆与黑焰伪造的回声，最终决定这座塔及其囚禁记忆的命运。

故事的核心问题不是“怎样打败怪物”，而是：

> 当一种安全建立在他人被遗忘的牺牲之上，玩家愿意维持它、摧毁它，还是承担更困难的修复？

### 1.1 战役位置

灰烬塔是四地图战役的必经起点，负责建立余烬灯、回声侵蚀、人物信任和结构化线索等核心玩法。玩家在这里处理的是第一处局部封印；任何区域结局都会继续开放沉钟港与无名林海。

### 1.2 地图输入与输出

**固定输入：**

- 余烬灯火 4；
- 回声侵蚀 0；
- 尚未认识守忆人；
- 不知道黑焰与记忆献祭的关系。

**战役输出：**

- `towerOutcome`：维持、释放、继任或重构；
- `archivistRelationship`：守忆人关系；
- 剩余灯火与回声侵蚀；
- 记忆证词和已履行／违背的誓言；
- 指向沉钟港的征集记录；
- 指向无名林海的余烬来源线索。

## 2. 核心游戏循环

```text
感知场景
  ↓
辨别事实与回声干扰
  ↓
选择观察、交涉、使用物品、移动或即兴行动
  ↓
规则层检查条件、资源、关系与风险
  ↓
产生进展、代价成功、失败推进或重大失败
  ↓
AI 根据已批准事实演绎结果
  ↓
资源、知识、关系和世界状态持续变化
```

每个大场景至少包含两种实质不同的推进方法。不同方法必须改变资源、人物关系、风险或最终结局条件，而不只是产生不同文案。

---

## 3. 跨场景状态

| 状态 | 范围 | 初始值 | 游戏作用 |
| --- | ---: | ---: | --- |
| 余烬灯火 | 0—6 | 4 | 照见隐藏事实、抵御黑焰、开启特殊解法 |
| 守忆人信任 | -2—2 | 0 | 决定其透露的信息及最终是否协助玩家 |
| 回声侵蚀 | 0—3 | 0 | 越高幻象越强；达到 3 将关闭部分安全解法 |
| 记忆证词 | 0—3 枚 | 0 | 证明封印真相并解锁最终重构方案 |
| 玩家誓言 | 无／守塔／查明真相／拒绝 | 无 | 改变守忆人态度和最终选择的道德代价 |
| 塔顶警觉 | 0—2 | 0 | 决定最终场景中黑焰的干扰强度 |

### 3.1 状态可见性

- 余烬灯火必须在 UI 中明确显示。
- 守忆人信任以态度描述呈现，不必直接显示数值。
- 回声侵蚀以稳定的感官征兆呈现，并在首次增加时解释其风险。
- 记忆证词作为明确线索列入侧栏。
- 誓言及其是否被违背必须可追溯。
- 塔顶警觉通过钟声、震动和黑焰活动频率反馈。

## 4. 总体情绪曲线

| 场景 | 主导情绪 | 强度 | 节奏作用 |
| --- | --- | ---: | --- |
| 1. 封印之门 | 好奇、戒备 | 2/5 | 建立神秘感与首次掌控 |
| 2. 守忆长厅 | 怀疑、短暂安全、道德不安 | 2→3/5 | 提供喘息并埋下冲突 |
| 3. 沉星档案井 | 压迫、惊奇、恐惧 | 4/5 | 第一次深入危险与重大揭示 |
| 4. 裂钟回廊 | 偏执、慌乱、释然 | 4→2/5 | 感知危机后的短暂释放 |
| 5. 灰烬阶梯 | 紧迫、背叛感、决心 | 5/5 | 收束前期后果并推向决战 |
| 6. 无火之塔 | 敬畏、诱惑、抉择、余韵 | 5→1/5 | 高潮、结局与情绪释放 |

整体节奏：

```text
神秘引入 → 安全假象 → 深潜恐惧 → 危机释放
                    → 真相反转 → 高压抉择 → 安静余韵
```

## 5. 第一场景：封印之门

### 5.1 场景职责

- 建立自然语言行动方式；
- 教会玩家使用余烬灯；
- 建立“表象可能欺骗，但世界规则稳定”的基调；
- 让第一次选择立即产生跨场景后果。

### 5.2 场景内容

断崖尽头矗立着一扇没有门缝的黑石门。三枚熄灭符文埋在石面中，分别对应“风、星、灰”。冷雨敲击石门，偶尔混入仿佛来自门后的三次轻响。

玩家需要理解封印规律并进入塔内。

### 5.3 不可变事实

- 门上存在三枚熄灭符文；
- 唯一道路通向门内，不存在绕过塔门的隐藏入口；
- 余烬灯能够照出被雨水遮蔽的刻痕；
- 门后敲击声不是一个真实人物发出的求救。

### 5.4 推进方法

#### 方法 A：观察并解开符文

用余烬灯照出刻痕，根据环境线索确定“风、星、灰”的激活顺序。

- 结果：安全进入；
- 获得：`符文规律`；
- 状态：保留灯火；
- 结果类型：`progress`。

#### 方法 B：强行灌注灯火

将余烬直接注入三枚符文，使门体短暂显出裂缝。

- 结果：门被强行开启；
- 代价：余烬灯火 -2；
- 持续影响：后续部分隐藏事实更难发现；
- 结果类型：`costly_success`。

#### 方法 C：模仿门后回声

按照敲击节奏回应封印，使塔误以为玩家属于内部回声。

- 结果：封印暂时放行；
- 代价：回声侵蚀 +1；
- 持续影响：之后的幻象会更早模仿玩家；
- 结果类型：`costly_success`。

### 5.5 失败推进

错误点亮符文不会导致死亡。错误激活会使其中一枚符文短暂显露真实图案，为玩家提供新线索，同时产生一次异常回声。

### 5.6 情绪节奏

```text
陌生 → 试探 → 微弱恐惧 → 首次掌控
```

玩家进入大厅时应明确感到：自己不是碰巧输入了正确指令，而是理解了世界的一条规律。

## 6. 第二场景：守忆长厅

### 6.1 场景职责

- 引入主要人物守忆人；
- 建立人物信任与誓言系统；
- 从环境危险转入社会判断；
- 埋下封印存在道德代价的疑问。

### 6.2 场景内容

空白石碑排列在长厅两侧，守忆人坐在残缺星图前。他声称塔顶黑焰必须被封存，却回避石碑为何没有姓名。

玩家需要取得前往档案井和塔顶的路线信息，并决定是否相信守忆人。

### 6.3 不可变事实

- 守忆人不能离开长厅，除非封印开始崩解；
- 星图指向塔顶，北侧阶梯是主要路线；
- 守忆人知道封印的代价，但不会无条件说出全部真相；
- 空白石碑的姓名是被人为磨除的。

### 6.4 推进方法

#### 方法 A：建立信任

分享在门前发现的符文规律，询问石碑与黑焰的关系。

- 结果：守忆人提供路线；
- 状态：信任 +1；
- 获得：`黑焰会模仿来访者最渴望听见的声音`；
- 持续影响：守忆人后续可能主动协助；
- 结果类型：`progress`。

#### 方法 B：绕开守忆人调查

检查星图、石碑背面和灰袍上的封印痕迹。

- 结果：取得路线并发现姓名被人为磨除；
- 获得：`守忆人隐瞒了建塔真相`；
- 状态：守忆人信任不变或在被发现时 -1；
- 结果类型：`progress` 或 `costly_success`。

#### 方法 C：威胁或欺骗

声称已经掌握塔的秘密，迫使守忆人放行。

- 结果：立即获得路线；
- 代价：信任 -1；
- 持续影响：守忆人不会主动解释最终封印；
- 结果类型：`costly_success`。

### 6.5 关键选择：誓言

守忆人要求玩家作出选择：

- 承诺维持封印；
- 承诺查明真相后再决定；
- 拒绝作出承诺。

誓言不会机械锁死结局，但违背誓言会改变守忆人的态度、协助意愿和结局叙事。

### 6.6 情绪节奏

```text
戒备 → 人际温度 → 短暂安全 → 道德不安
```

玩家离开时应开始怀疑：“封印黑焰”是否等同于“做正确的事”。

## 7. 第三场景：沉星档案井

### 7.1 场景职责

- 揭露灰烬塔封印的真正燃料；
- 将抽象谜团转化为具体受害者；
- 首次显著消耗玩家资源；
- 形成第一轮情绪高峰。

### 7.2 场景内容

一口向下延伸的圆形档案井，石壁嵌满封存声音的玻璃匣。井底积着不会反光的黑水，残缺星图的另一半悬在中央。

玩家需要取得至少一份记忆证词以及通往上层的完整路线。

### 7.3 不可变事实

- 玻璃匣中封存的是真实记忆，而非黑焰制造的幻象；
- 黑水会增加回声侵蚀；
- 星图路线可以通过机构、灯火或记忆证词取得；
- 玩家不可能在一个周目中无代价地救出全部记忆。

### 7.4 推进方法

#### 方法 A：修复升降机构

观察配重轮的磨损规律，修复井壁升降台。

- 结果：安全取得一份证词和完整路线；
- 状态：不消耗灯火；
- 结果类型：`progress`。

#### 方法 B：用余烬牵引玻璃匣

留在井口，用余烬灯使特定记忆浮起。

- 结果：可选择一份记忆证词；
- 代价：灯火 -1；
- 结果类型：`costly_success`。

#### 方法 C：进入黑水

直接涉入井底搜索被沉没的档案。

- 结果：取得两份证词；
- 代价：回声侵蚀 +1；
- 持续影响：之后会听见档案主人的声音；
- 结果类型：`costly_success`。

### 7.5 重大揭示

玩家确认：

- 黑焰不是普通火焰，而是在吞食并重复记忆；
- 塔的封印通过持续向黑焰提供记忆维持稳定；
- 长厅空白石碑属于被献出记忆的人；
- 守忆人参与了封印机制的建立。

### 7.6 失败推进

升降机构失控时，玩家不会直接坠亡，而会被迫落到更深的平台：

- 灯火 -1；
- 获得一份隐藏证词；
- 原路返回被关闭，只能继续向前。

### 7.7 情绪节奏

```text
幽闭压迫 → 探索惊奇 → 人性冲击 → 逃离欲望
```

玩家的目标应在此从“解决塔里的谜题”转变为“判断这个封印制度是否值得维持”。

## 8. 第四场景：裂钟回廊

### 8.1 场景职责

- 检验玩家是否真正理解已获得的事实；
- 通过真假声音制造感知危机；
- 让前期获得的知识、信任和资源开始产生组合效果；
- 在高压之后提供一次明确的释放。

### 8.2 场景内容

回廊悬挂着十二口破裂铜钟。每次钟响，墙壁都会显现一条似乎不同的道路；部分声音会模仿守忆人或记忆证词的主人。

玩家需要找到真实的北侧阶梯。

### 8.3 不可变事实

- 塔顶没有其他出口；
- 真正的阶梯位于北侧；
- 黑焰幻象无法投下稳定影子；
- 幻象只能重复已有信息，不能提供玩家从未获得的真实秘密。

### 8.4 推进方法

#### 方法 A：使用事实排除幻象

结合已确认事实、方向线索和影子规律寻找真实阶梯。

- 结果：安全通过；
- 奖励：回声侵蚀 -1；
- 结果类型：`progress`。

#### 方法 B：破坏钟阵

固定钟舌或击碎控制幻象的核心铜钟。

- 结果：幻象停止，阶梯显现；
- 代价：塔顶警觉 +1；
- 持续影响：最终场景干扰增强；
- 结果类型：`costly_success`。

#### 方法 C：借助守忆人的回应

若信任足够，守忆人会通过石碑传来无法被黑焰完整复制的反向誓词。

- 结果：获得安全路线；
- 代价：守忆人受到侵蚀；
- 持续影响：其最终协助能力下降；
- 结果类型：`costly_success`。

### 8.5 关键选择：受困回声

一段被困的记忆请求玩家将其带走：

- 带走：证词 +1，回声侵蚀 +1；
- 留下：保持安全，但失去一种最终解法；
- 收入余烬灯：保存回声，灯火上限永久 -1。

这段回声是被保存的记忆人格，不是仍然活着的人。AI 不得把选择描述成确定意义上的“救活”或“杀死”。

### 8.6 情绪节奏

```text
困惑 → 偏执 → 感知失控 → 识破 → 短暂释然
```

场景结束后应安排短暂安静，让玩家感到自己是通过理解世界而成功。

## 9. 第五场景：灰烬阶梯

### 9.1 场景职责

- 回收此前的资源、证词、关系与誓言；
- 揭露守忆人的责任；
- 在高潮前迫使玩家形成明确立场；
- 设置最终检查点。

### 9.2 场景内容

通往塔顶的阶梯正在崩裂。墙面不断闪现封印建立时的残影：守忆人曾参与建塔，并亲手抹去献祭者的姓名。

根据前期状态，守忆人可能亲自出现，也可能只通过回声与玩家对话。

### 9.3 不可变事实

- 守忆人参与建立了以记忆维持的封印；
- 建塔时黑焰确实即将吞没周边聚落；
- 守忆人亲手抹去姓名，目的是维持封印稳定并掩盖责任；
- 他不能单独重构封印，也不能替玩家决定最终方案。

### 9.4 推进方法

#### 方法 A：用灯火稳定阶梯

修复阶梯上的星图节点。

- 结果：安全抵达塔顶；
- 代价：灯火 -1；
- 持续影响：旧封印更容易维持；
- 结果类型：`costly_success`。

#### 方法 B：沿残影路线穿越

根据档案证词辨认建塔者当年的安全路线。

- 条件：至少一份记忆证词；
- 结果：不消耗灯火；
- 风险：证词不足时回声侵蚀 +1；
- 结果类型：`progress` 或 `costly_success`。

#### 方法 C：要求守忆人承担责任

使用证词和石碑证据要求守忆人稳定阶梯。

- 高信任：守忆人自愿协助；
- 低信任：守忆人拒绝或阻挡玩家；
- 持续影响：决定最终场景是否存在盟友；
- 结果类型：`progress`、`blocked` 或 `failed_forward`。

### 9.5 核心真相

守忆人不是单纯恶人，也不是无辜守护者：

- 他参与建立了残酷封印；
- 当时他相信牺牲少数记忆是唯一办法；
- 多年以来，他已经无法确定自己是在保护世界，还是在保护自己的罪行；
- 玩家必须依据事实判断，而不是接受系统指定的道德答案。

### 9.6 情绪节奏

```text
紧迫 → 真相反转 → 愤怒或悲悯 → 坚定
```

本场结束时设置最终检查点，保存全部资源、证词、关系、誓言和消息状态。

## 10. 第六场景：无火之塔

### 10.1 场景职责

- 将所有资源、关系、证词和誓言转化为最终选择；
- 让结局来自玩家此前行动，而不是固定答案；
- 完成情绪高潮与主题收束。

### 10.2 场景内容

塔顶中央悬浮着一团冰冷黑焰。它依次使用守忆人、档案亡者以及玩家曾信任的声音说话，却不能提供任何此前未知的真实事实。

黑焰提出诱惑：只要玩家献出一段记忆，它就会让某个声音永远留下。

AI 可以根据已发生的对话选择模仿对象，但不得擅自创造玩家的亲人、过去或“最爱之人”。

### 10.3 区域结局 A：维持旧封印

使用余烬灯完成封存，并献出一份记忆。

- 条件：灯火至少 1；
- 结果：塔恢复稳定；
- 代价：以记忆为燃料的机制继续存在；
- 主题：秩序是否值得不被看见的牺牲；
- 情绪：苦涩的安全；
- 战役影响：沉钟港继续供应记忆，玩家以封印维护者身份进入后续地图；
- 结果类型：`complete`。

### 10.4 区域结局 B：释放所有记忆

打碎封印，让黑焰失去食粮。

- 条件：掌握封印原理或拥有至少两份证词；
- 结果：被囚记忆返回原主或化为回声消散；
- 代价：塔开始坍塌，玩家必须逃离；
- 主题：自由可能伴随不可控后果；
- 情绪：激烈、悲壮、开放；
- 战役影响：沉钟港出现记忆回流，无名林海更早感知循环异常；
- 结果类型：`complete`。

### 10.5 区域结局 C：继任守忆人

玩家主动接受塔的权柄，代替守忆人管理献祭。

- 条件：必须是玩家明确表达的主动选择；
- 结果：灾难被延后；
- 代价：玩家留在塔内；
- 主题：掌权是否真的能净化错误制度；
- 情绪：冷寂、循环感；
- 战役影响：玩家获得封印网络身份，同时被部分人物视为旧制度继承者；
- 结果类型：`complete`。

### 10.6 区域结局 D：重构封印

以公开的记忆证词、守忆人的承认和余烬灯共同分离黑焰与被囚记忆。

- 条件：记忆证词至少 3；
- 条件：守忆人信任不低于 1；
- 条件：灯火至少 2；
- 条件：回声侵蚀低于 3；
- 结果：黑焰被封存，但不再以被夺记忆为燃料；
- 代价：守忆人失去永生，灰烬塔永久熄灭；
- 主题：修复需要真相、责任与共同承担；
- 情绪：艰难释放、安静希望；
- 战役影响：证明局部封印可以改革，并提高沉钟港改革派与无名林海的初始认可；
- 结果类型：`complete`。

### 10.7 情绪节奏

```text
敬畏 → 诱惑 → 恐惧峰值 → 明确抉择 → 后果爆发 → 安静余韵
```

结局后先用一段克制的环境变化呈现玩家选择留下的世界，再展示结局名称和关键状态总结。不要在抉择完成后立即用奖励面板打断余韵。

### 10.8 战役交接

区域结局完成后，系统应明确展示两条新路线：沉钟港的征集船册与无名林海的余烬年轮。玩家可以自由选择下一张地图，不需要取得“最佳”灰烬塔结局。

## 11. 场景之间的持续后果

| 早期选择 | 中后期影响 |
| --- | --- |
| 强行开启封印之门 | 灯火减少，档案井与最终场景的安全方法受限 |
| 模仿门后回声 | 更早受到幻象影响，但可识别部分回声节奏 |
| 对守忆人保持诚实 | 获得协助和重构封印的可能 |
| 欺骗或威胁守忆人 | 快速推进，但失去部分真相与盟友支持 |
| 进入档案井黑水 | 获得更多证词，同时承担侵蚀风险 |
| 破坏裂钟钟阵 | 快速通过，但提高塔顶警觉 |
| 带走受困回声 | 增加最终证词，同时提高侵蚀 |
| 履行或违背誓言 | 改变守忆人的协助、阻挡与结局评价 |

## 12. 情绪节奏控制原则

### 场景 1：不要过早制造死亡威胁

以未知吸引玩家，让第一次成功建立能力感。

### 场景 2：提供人物温度

守忆人必须存在值得信任的一面，否则后续背叛感和道德冲突无法成立。

### 场景 3：展示具体代价

恐惧应来自理解封印机制，而不只是黑暗、尖叫和怪物描写。

### 场景 4：危机之后必须释放

玩家识破幻象后，应给予短暂安静和清晰确认，避免持续疲劳。

### 场景 5：以道德真相取代新怪物

高潮前的主要压力来自责任与立场，而不是继续堆叠敌人。

### 场景 6：把胜负问题转化为代价问题

最终抉择不应是“哪个按钮正确”，而应是“玩家愿意让谁承担什么后果”。

## 13. AI 叙事边界

AI 可以：

- 根据场景状态描写感官细节；
- 模仿玩家已经听过的声音；
- 把规则层批准的结果演绎成符合气氛的叙事；
- 对不确定现象保持不确定表达；
- 根据事件重要性控制篇幅。

AI 不得：

- 创造不存在的场景出口、人物或物品；
- 让黑焰提供玩家尚未获得的真实秘密；
- 擅自修改灯火、信任、侵蚀、证词或警觉；
- 替玩家设定亲人、往事、恐惧或最渴望的声音；
- 把记忆回声描述成确定意义上的活人；
- 替玩家选择结局或作出不可逆承诺；
- 用长篇气氛描写掩盖行动没有产生有效反馈。

## 14. 内容验收清单

- [ ] 六个场景均至少存在两种实质不同的推进方法。
- [ ] 每个主线必要线索至少有两种获得方式。
- [ ] 任一非致命失败都能提供信息、改变局面或产生代价。
- [ ] 灯火、信任、侵蚀、证词、誓言和警觉均能跨场景生效。
- [ ] 不存在因错过单一线索造成的永久死锁。
- [ ] 严重失败前存在明确风险预告。
- [ ] 否定表达不会被解释为执行危险行为。
- [ ] 四种结局均由结构化状态判定，不由 AI 自由决定。
- [ ] 模型不可用时仍可通过本地分类与模板完成冒险。
- [ ] 检查点能够完整恢复物品、线索、状态和消息。
- [ ] 普通动作保持简短，新场景、重大揭示和结局才展开叙事。
- [ ] 黑焰的所有“新信息”都能被验证为重复、扭曲或诱导，而非真实线索。

## 15. 最终设计准则

> 六个场景不是六段依次播放的剧情，而是六组相互传递资源、知识、关系和责任的状态系统。

玩家最终面对的结局，必须能够追溯到之前如何进入塔门、如何对待守忆人、愿意为证词承担多少风险，以及是否在幻象中坚持已经确认的事实。
