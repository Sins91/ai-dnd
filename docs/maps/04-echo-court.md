# 地图四《回声王庭》六大场景内容大纲

> 战役职责：汇总前三张地图的事实、支持、资源与代价，决定整个记忆网络的未来  
> 所属战役：[四地图战役整体框架](../CAMPAIGN_MAP_FRAMEWORK.md)  
> 建议游戏时长：90—120 分钟  
> 固定为完成灰烬塔、沉钟港与无名林海后的最终地图

---

## 1. 核心体验承诺

玩家带着局部封印实践、社会证词和自然循环知识进入记忆网络的中央王庭，不是寻找一个隐藏的正确按钮，而是在真实能力与真实代价之间决定文明今后如何保存、归还和遗忘记忆。

核心问题：

> 推翻一个以牺牲维持的制度之后，谁有权设计替代它的制度，又由谁承担过渡期的风险？

### 1.1 固定进入条件

- 已完成灰烬塔区域结局；
- 已完成沉钟港区域结局；
- 已完成无名林海区域结局；
- 已保存三张地图全部结构化输出；
- 不要求前三张地图均取得最佳结果。

### 1.2 最终输出

- `campaignOutcome`：维持、接管、摧毁、重构或碎片化自治；
- 记忆网络最终状态；
- 各地区和盟友承担的责任；
- 未解决代价与未来风险；
- 玩家承诺的履行或违背情况；
- 一段基于真实状态生成的世界余韵。

## 2. 最终地图状态

| 状态 | 来源 | 作用 |
| --- | --- | --- |
| 局部实践 | 灰烬塔结局 | 证明玩家如何实际处理过黑焰封印 |
| 社会授权 | 沉钟港公众与代表 | 决定改革是否有人类执行者和见证者 |
| 替代规律 | 无名林海知识与契约 | 决定新系统是否符合世界规律 |
| 王庭稳定度 | 0—3 | 决定中央网络可承受多少改造或破坏 |
| 公开证据 | 0—3 | 决定王庭成员和外界能否否认制度责任 |
| 联盟席位 | 0—3 | 守忆人、港口代表、林海代表可各占一席 |
| 中央权限 | 0—3 | 通过印记、总账和根路取得的系统控制能力 |
| 过渡负担 | 0—3 | 代表尚未被分配的记忆回流与地区风险 |

### 2.1 禁止抽象化

不设置隐藏“善恶值”。所有世界结局必须依据具体成果：

- 是否有局部成功案例；
- 是否有人愿意执行和监督；
- 是否掌握可运行的替代原理；
- 是否保留足够系统稳定性；
- 玩家把风险分配给了谁。

## 4. 场景一：空席渡桥

### 4.1 场景职责

- 把前三地图关系转化为实际随行者、证词或缺席；
- 建立最终地图不再补发资源的规则；
- 让玩家确认需要带入王庭的代表与证据；
- 预告中央网络正在失稳。

### 4.2 场景内容

回声王庭悬在由记忆流构成的暗海上。渡桥两侧排列着空椅，每一把都对应曾经参与建立网络的地区。玩家能够带上桥的，不是所有遇见过的人，而是此前真正愿意承担风险的代表。

### 4.3 不可变事实

- 缺席的盟友不会因最终需要而突然出现；
- 证词副本不能完全替代愿意承担责任的活人代表；
- 玩家最多携带三类核心成果进入王庭主区；
- 未携带的成果不会消失，但在法庭上无法即时调用；
- 王庭失稳来自长期过度抽取，不是玩家抵达才触发的巧合。

### 4.4 推进方法

#### 方法 A：组成三方代表团

- 条件：至少两张地图产生合作型结局；
- 结果：联盟席位增加，公开进入王庭；
- 代价：所有代表都将承担后续网络反冲；
- 类型：`progress`。

#### 方法 B：独自携带证据进入

- 结果：行动隐蔽，不必让盟友冒险；
- 代价：联盟席位较低，法庭中的社会授权论据受限；
- 类型：`costly_success`。

#### 方法 C：以守忆人或中央身份进入

- 条件：灰烬塔继任，或守忆人仍支持玩家；
- 结果：获得中央权限 +1；
- 代价：王庭会把玩家视为旧制度内部人员，公众代表信任可能下降；
- 类型：`costly_success`。

### 4.5 失败推进

若没有任何盟友且缺少正式权限，渡桥会将玩家导向维修通道。玩家仍可进入，但过渡负担 +1，法庭只能通过公开泄露证据而非正式听证推进。

### 4.6 情绪节奏

```text
远望终点 → 看见空席 → 清点真实同行者 → 接受此前选择的重量
```

## 5. 场景二：千门前庭

### 5.1 场景职责

- 将三张地图成果转化为不同权限；
- 让玩家选择合法、技术或自然路径进入核心；
- 揭示王庭不是宫殿，而是记忆网络的控制界面；
- 确认哪些系统操作在当前周目真实可用。

### 5.2 场景内容

前庭立着上千扇没有墙体的门。每扇门对应一种被制度承认的身份：守忆人、征忆官、捐献者、无名者、林海契约者。门不会回答问题，只会根据结构化凭证开放不同区域。

### 5.3 不可变事实

- 门只识别真实状态和凭证，无法被精彩说辞欺骗；
- 灰烬塔印记提供封印权限；
- 沉钟港总账提供行政权限；
- 无名林海年轮印提供自然根路权限；
- 至少一种凭证足以推进主线，三种齐全才可访问完整重构界面。

### 5.4 推进方法

#### 方法 A：使用三类凭证建立完整权限

- 条件：拥有塔印、总账与年轮印；
- 结果：中央权限达到 3；
- 类型：`progress`。

#### 方法 B：组合任意两类权限

- 结果：进入王庭主要区域；
- 代价：某一类最终方案需要额外承担风险；
- 类型：`progress`。

#### 方法 C：通过维修根路绕开门阵

- 条件：拥有林海根路坐标；
- 结果：进入中央回响库侧层；
- 代价：公开证据暂时无法提交，过渡负担 +1；
- 类型：`costly_success`。

#### 方法 D：使用高容量根火或强制封印权破门

- 条件：夺取根火或继任守忆人；
- 结果：中央权限 +1并强行进入；
- 代价：王庭稳定度 -1；
- 类型：`costly_success`。

### 5.5 失败推进

错误凭证不会消耗关键物品。对应门会展示该凭证缺少的来源，使玩家明确知道哪类权限不可用，并开放最低权限的听证入口。

### 5.6 情绪节奏

```text
宏大压迫 → 身份被分类 → 前期成果得到确认 → 进入制度内部
```

## 6. 场景三：记忆法庭

### 6.1 场景职责

- 公开确立记忆网络的制度责任；
- 让旧制度维护者提出最强而非愚蠢的反对意见；
- 检查伤害证据、社会授权和替代能力；
- 决定改革是在公开监督下进行还是被迫秘密执行。

### 6.2 场景内容

法庭由九个合唱席组成。席位并非单独人物，而是历代管理者记忆的制度化集合。它们承认献忆造成伤害，却主张没有中央网络，黑焰与失控记忆将在数月内摧毁多个地区。

### 6.3 不可变事实

- 合唱席不能篡改总账原件和有效证词；
- 旧网络确实承担了一部分灾害控制功能；
- 立即关闭网络会产生真实过渡风险；
- “制度曾救过人”不能自动免除其强征责任；
- 玩家必须分别证明伤害、替代方案和执行能力，三者不能互相替代。

### 6.4 推进方法

#### 方法 A：正式公开听证

- 条件：公开证据至少 2、联盟席位至少 1；
- 结果：旧制度责任被记录，公开证据达到 3；
- 类型：`progress`。

#### 方法 B：以内部权限质询

- 条件：中央权限至少 2；
- 结果：取得系统灾害预测与隐瞒记录；
- 代价：听证不向外界公开，社会授权不增加；
- 类型：`costly_success`。

#### 方法 C：向所有地区广播证词

- 结果：绕开法庭封锁，使事实公开；
- 代价：王庭稳定度 -1、部分地区出现恐慌；
- 类型：`costly_success`。

### 6.5 关键对峙

法庭依次提出三个问题：

1. 哪些具体伤害证明旧制度不能原样继续？
2. 如果停止献忆，黑焰和记忆回流如何处理？
3. 谁愿意长期执行、监督并承担失败责任？

规则层根据总账、证词、自然封印知识、地区结局和代表席位判断可用回答。AI 只负责组织对话，不得判定玩家“说得感人所以成功”。

### 6.6 失败推进

若玩家无法证明完整改革能力，法庭不会结束游戏，而会开放有限维护权限，并要求玩家进入中央回响库理解系统负担。缺失项会明确记录为最终方案限制。

### 6.7 情绪节奏

```text
正式克制 → 责任争辩 → 旧制度提出真实风险 → 玩家立场经受检验
```

## 7. 场景四：中央回响库

### 7.1 场景职责

- 展示记忆网络的真实规模；
- 揭露系统最初目标与后来扩张的差异；
- 要求玩家确定过渡期优先保护对象；
- 为王庭断层分配资源与负担。

### 7.2 场景内容

回响库保存着数代人的记忆索引，不是每一段记忆本身。最早记录显示网络原本只为分流自然灾害，后来为维持自身稳定而不断扩大征忆范围。三个区域已经接近失稳：黑焰封印、身份档案和林海根脉。

### 7.3 不可变事实

- 网络不能在一次操作中无代价完成全部迁移；
- 索引损毁会让部分记忆无法找到归还对象；
- 保留全部索引会延长中央控制；
- 自然循环可以接纳部分回流，但需要时间和地区同意；
- 玩家必须明确优先级，AI 不得自动替玩家选择“最善良”方案。

### 7.4 推进方法

#### 方法 A：优先保护个人归还索引

- 结果：未来可把更多记忆归还个人；
- 代价：灾害控制模型不完整，王庭稳定度 -1；
- 类型：`costly_success`。

#### 方法 B：优先保护地区稳定模型

- 结果：降低网络改造风险；
- 代价：部分个人索引无法恢复，公众支持可能下降；
- 类型：`costly_success`。

#### 方法 C：优先保护制度责任记录

- 结果：未来无法抹去强征历史，公开证据保持最高；
- 代价：归还速度和系统稳定都受到轻微损失；
- 类型：`costly_success`。

#### 方法 D：分散保存三类索引

- 条件：联盟席位达到 3；
- 结果：三个代表分别承担一类索引，避免中央单点控制；
- 代价：所有代表承受长期回声负担；
- 类型：`progress`。

### 7.5 失败推进

若玩家延迟选择导致索引脱落，系统会保留此前在对话中明确表达的优先项，并使另一项部分损毁。过渡负担 +1，但不会随机抹除未曾讨论的关键成果。

### 7.6 情绪节奏

```text
规模敬畏 → 看见制度自我扩张 → 无法全保的哀悼 → 确立优先责任
```

## 8. 场景五：王庭断层

### 8.1 场景职责

- 形成最终动作与系统高潮；
- 把“谁承担过渡风险”变成实际规则；
- 检验联盟、资源和地区结局是否能协同；
- 设置最终选择前检查点。

### 8.2 场景内容

法庭广播和回响库迁移使中央网络进入重分配。三道断层同时出现：黑焰压力倒灌、港口身份索引过载、林海根脉排斥。玩家必须分配灯火、权限、盟友与地区承担这些负担。

### 8.3 不可变事实

- 三道断层都是真实风险；
- 没有对应盟友或知识时，玩家必须用资源或接受后果补足；
- 一名盟友不能同时完整承担两道断层；
- 高回声侵蚀会增加玩家亲自承担负担的风险；
- 断层稳定方式决定最终方案的实际代价。

### 8.4 负担处理

#### 黑焰压力

- 守忆人或灰烬塔重构实践可安全承担；
- 否则消耗灯火 2；
- 若无人承担：一个外围封印失效，过渡负担 +1。

#### 港口身份索引

- 港口代表与运行档案可安全承担；
- 否则需要保留中央行政控制；
- 若无人承担：大量身份进入待核验状态，过渡负担 +1。

#### 林海根脉

- 林海契约与自然封印知识可安全承担；
- 否则可强制向林海转移；
- 强制转移：林海认可下降且过渡负担 +1。

### 8.5 玩家亲自承担

玩家可以亲自承担任意一道断层，但必须是明确选择：

- 承担黑焰：回声侵蚀 +1；
- 承担身份索引：最终余韵中长期听见他人身份片段；
- 承担根脉：余烬灯永久与玩家绑定。

AI 不得默认玩家愿意牺牲自己。

### 8.6 失败推进与重大失败

- 普通分配不足产生过渡负担，不触发死亡；
- 过渡负担达到 3 时，重构结局关闭，但其他结局仍可用；
- 只有玩家在明确预警后主动同时承受三道断层，才可能触发重大失败或牺牲结局；
- 场景结束后建立最终检查点。

### 8.7 情绪节奏

```text
系统崩裂 → 多线告急 → 分配真实负担 → 盟友承担或玩家牺牲 → 短暂停顿
```

## 9. 场景六：万忆中枢

### 9.1 场景职责

- 执行世界级最终选择；
- 严格根据前五场与前三地图状态开放方案；
- 呈现每种制度的收益、代价和未决问题；
- 生成基于事实而非泛化善恶评价的结局余韵。

### 9.2 场景内容

中枢不是王座，而是一组可以改变记忆流向的结构化操作。九席合唱承诺：若玩家保留中央权力，它将停止当前危机；若玩家改变系统，则必须自行指定新的见证、归还和监督机制。

### 9.3 世界结局 A：维持网络

- 基本条件：始终可用，除非王庭稳定度为 0；
- 执行：修复中央网络并调整局部配额；
- 优势：灾害与身份系统快速稳定；
- 代价：中央征忆继续存在，改革仅限减轻伤害；
- 适配成果：灰烬塔维持、港口监管、林海封闭；
- 输出：`campaignOutcome = maintained`。

### 9.4 世界结局 B：接管网络

- 条件：中央权限至少 2，并拥有守忆人身份、行政档案或足够联盟席位之一；
- 执行：由玩家或指定联盟替代九席合唱；
- 优势：能够立即停止强征并渐进改革；
- 代价：权力仍然集中，接管者长期承受回声侵蚀；
- 输出：`campaignOutcome = inherited`。

### 9.5 世界结局 C：摧毁网络

- 条件：玩家明确选择并确认已预告风险；
- 执行：切断全部中央索引和封印调度；
- 优势：中央再也无法征收或控制记忆；
- 代价：根据过渡负担产生地区封印失效、身份混乱和记忆风暴；
- 若拥有自然根路与港口自治，代价显著降低；
- 输出：`campaignOutcome = destroyed`。

### 9.6 世界结局 D：重构网络

- 条件：存在局部改革实践或守忆人支持；
- 条件：总账证据至少 2、公众支持至少 1；
- 条件：`naturalSealKnowledge = true`；
- 条件：林海认可不低于 0；
- 条件：过渡负担不高于 2；
- 执行：将网络改为“见证—归还—留白”循环，停止永久中央占有；
- 优势：保留跨地区协调，同时终止记忆燃料制度；
- 代价：需要持续公开监督，部分旧索引必须接受自然消散；
- 输出：`campaignOutcome = reconstructed`。

### 9.7 世界结局 E：碎片化自治

- 条件：至少两个地区产生自治或合作型结局；
- 条件：联盟席位至少 2；
- 执行：中央网络拆分为地区节点，彼此只交换灾害预警而不交换个人记忆；
- 优势：终止中央垄断，各地保留制度选择权；
- 代价：地区之间标准不一，弱小地区可能缺乏维护能力；
- 输出：`campaignOutcome = federated`。

### 9.8 特殊牺牲结局

若玩家主动承担全部三道断层，可用自身作为一次性过渡媒介完成原本条件不足的重构或摧毁缓冲。

- 必须经过明确风险确认；
- 不得由含糊表达、单个关键词或模型推断触发；
- 这是代价型替代结局，不应被标记为唯一真结局。

### 9.9 情绪节奏

```text
面对控制权 → 旧秩序诱惑 → 回看所有代价 → 明确执行 → 世界回应 → 安静余韵
```

## 10. 结局余韵生成规则

结局叙事必须依次呈现：

1. 中枢发生的确定变化；
2. 灰烬塔的局部回应；
3. 沉钟港普通人的可见变化；
4. 无名林海循环的变化；
5. 盟友与缺席者承担的后果；
6. 玩家誓言是否履行；
7. 一个仍未被完全解决的问题。

结局不得只用“好结局”“坏结局”概括。相同世界结局也应根据地区状态产生不同余韵。

## 11. 跨场景持续后果

| 早期行动 | 后续影响 |
| --- | --- |
| 携带三方代表 | 提高法庭公开性和分散索引能力 |
| 独自进入 | 降低盟友风险，但限制社会授权 |
| 强行破门 | 快速取得权限，同时降低系统稳定 |
| 公开广播证据 | 防止责任被抹除，同时增加恐慌和失稳 |
| 优先保存个人索引 | 提高归还能力，降低灾害预测完整性 |
| 优先保存稳定模型 | 降低过渡风险，牺牲部分个体可追溯性 |
| 分散索引 | 开放自治路线，让代表长期承担负担 |
| 玩家亲自承担断层 | 补足缺失能力，产生个人长期代价 |

## 12. AI 叙事边界

AI 可以描写：

- 王庭如何根据真实凭证承认或拒绝权限；
- 九席合唱对旧制度提出有事实依据的辩护；
- 盟友根据既有关系承担或拒绝风险；
- 最终状态在四张地图中的具体余韵。

AI 不得：

- 临时生成缺失盟友、总账、年轮印或自然知识；
- 让一次演说替代结局条件；
- 把旧制度写成毫无作用的纯粹邪恶装置；
- 隐瞒摧毁、接管或重构的已知代价；
- 替玩家决定优先保存对象、牺牲自己或选择结局；
- 用抽象“世界恢复和平”代替各地区具体变化；
- 宣称重构结局没有长期维护成本。
