# 《灰烬塔的回声》四地图战役整体框架

> 文档性质：全局地图关系、主题递进与跨地图状态设计  
> 设计依据：[AI 文字冒险设计圣经](../.agents/skills/design-ai-adventures/references/design-bible.md)  
> 地图细纲：见下方四地图概览中的独立文档链接  
> 内容粒度：只定义四张地图的关系，不展开各地图内部场景

---

## 1. 战役定位

整个游戏由四张大地图组成，每张地图内部规划六个大场景。

现有的“封印之门、守忆长厅、沉星档案井、裂钟回廊、灰烬阶梯、无火之塔”合称第一张地图 **灰烬塔**。

四张地图共同围绕一个问题展开：

> 当一种安全建立在他人被夺走的记忆之上，玩家应该维持、接管、摧毁，还是重新设计这套制度？

战役不采用四张地图互不相关的关卡结构。每张地图分别揭示同一问题的不同层面，并把可验证的事实、资源、人物支持和代价传递到最终地图。

---

## 2. 四张地图概览

| 地图 | 战役职责 | 核心问题 | 主要产出 |
| --- | --- | --- | --- |
| [1. 灰烬塔](maps/01-ashen-tower.md) | 发现问题 | 为了安全，可以牺牲他人的记忆吗？ | 第一处封印的处理结果、守忆人关系、黑焰知识 |
| [2. 沉钟港](maps/02-sunken-bell-harbor.md) | 展示社会后果 | 当记忆可以买卖时，它属于个人还是集体？ | 受害者证词、公众支持、记忆交易记录 |
| [3. 无名林海](maps/03-nameless-forest.md) | 揭示力量起源 | 遗忘是伤害，还是生命循环的一部分？ | 余烬与黑焰的起源、替代封印原理、林海认可 |
| [4. 回声王庭](maps/04-echo-court.md) | 解决系统问题 | 应该摧毁、接管还是重构整个记忆体系？ | 世界级最终结局 |

## 3. 地图拓扑关系

```text
                        ┌────────────────┐
                        │  2. 沉钟港     │
                        │  社会与制度     │
                        └───────┬────────┘
                                │
┌────────────────┐      两者均完成      ┌────────────────┐
│  1. 灰烬塔     │ ───────────────────→ │  4. 回声王庭   │
│  必经起点       │                      │  最终汇合       │
└────────────────┘      两者顺序自由      └────────────────┘
                                │
                        ┌───────┴────────┐
                        │  3. 无名林海   │
                        │  起源与规律     │
                        └────────────────┘
```

### 3.1 游玩顺序

1. 灰烬塔是固定起点，用于建立玩法规则并揭露第一处记忆封印。
2. 完成灰烬塔后，同时开放沉钟港与无名林海。
3. 沉钟港和无名林海可以自由选择先后顺序。
4. 两张中期地图都完成后，回声王庭才会开放。
5. 回声王庭根据前三张地图的真实状态生成可用方案，而不是临时提供所有结局。

### 3.2 结构目的

- 保留明确主线，避免完全开放导致目标模糊；
- 给中期提供一次有意义的顺序选择；
- 让两张中期地图彼此改写部分初始状态和角色反应；
- 让最终结局能够追溯到整个战役，而不是只取决于最后一句输入。

## 4. 第一地图：灰烬塔

### 4.1 战役职责

灰烬塔是整个记忆封印网络的外围节点。玩家在这里第一次接触余烬灯、黑焰、守忆人和以记忆维持安全的机制。

第一地图负责让玩家从“调查一座异常高塔”转变为“意识到这是一套遍布世界的制度”。

### 4.2 与后续地图的连接

灰烬塔留下两条可验证线索：

- 空白石碑和档案记录指向记忆供应地 **沉钟港**；
- 余烬灯灯芯与黑焰残留指向力量来源 **无名林海**。

### 4.3 地图结局定位

灰烬塔原有四种结局调整为第一地图的区域结局，而不是全游戏结局：

- 维持旧封印；
- 释放被囚记忆；
- 继任守忆人；
- 重构局部封印。

这些结果决定玩家以什么身份、资源和声誉进入后续地图，但无论选择哪一种，都能继续完整战役。

---

## 5. 第二地图：沉钟港

### 5.1 战役职责

沉钟港展示灰烬塔封印在人类社会中的实际代价。港口长期以“自愿捐献记忆”的名义为各地封印节点供应燃料，这套制度后来演变为交易、债务、欺骗和强制征收。

灰烬塔展示牺牲本身，沉钟港则展示牺牲如何被包装成合法制度。

### 5.2 与灰烬塔的因果关系

灰烬塔的处理结果改变沉钟港的开局：

| 灰烬塔结果 | 沉钟港初始变化 |
| --- | --- |
| 维持旧封印 | 港口继续失去记忆，但表面秩序稳定 |
| 释放被囚记忆 | 大量记忆突然返回，引发身份和所有权冲突 |
| 继任守忆人 | 玩家被港口管理者视为封印体系的新代表 |
| 重构局部封印 | 旧记录被公开，港口开始追究历史责任 |

### 5.3 对后续地图的贡献

沉钟港主要提供：

- 记忆征集制度的原始记录；
- 被剥夺者和获益者的证词；
- 人类社会对改革、维持或摧毁体系的支持；
- 通向回声王庭的行政与历史线索。

这些成果决定最终行动是否具有社会正当性，以及制度崩溃后是否有人愿意承担重建工作。

---

## 6. 第三地图：无名林海

### 6.1 战役职责

无名林海揭示余烬灯和黑焰的共同起源。林海原本会自然吸收、分解并归还死者与遗忘之物的记忆；建塔者强行截断这一循环，才创造出必须持续吞食记忆的黑焰。

沉钟港讨论“谁拥有记忆”，无名林海则进一步追问“记忆是否必须永远被保存”。

### 6.2 与灰烬塔的因果关系

玩家携带的余烬灯、黑焰侵蚀和封印处理方式会改变林海对玩家的回应：

- 大量消耗余烬会被视为继续掠夺林海；
- 保存记忆回声会让林海承认玩家理解记忆的重量；
- 继任守忆人会令部分林海存在将玩家视为建塔者继承人；
- 重构灰烬塔封印能证明旧制度并非不可改变。

### 6.3 对后续地图的贡献

无名林海主要提供：

- 余烬、黑焰与自然遗忘之间的真实关系；
- 不依靠持续献祭的替代封印原理；
- 林海是否愿意重新参与世界记忆循环的认可；
- 通向回声王庭核心结构的自然路径。

这些成果决定玩家在最终地图中是否拥有重构体系的技术与世界规律依据。

---

## 7. 沉钟港与无名林海的双向关系

两张中期地图不是彼此独立的支线。先完成哪一张，会改变进入另一张地图时的知识和立场。

### 7.1 先完成沉钟港

玩家带着受害者证词和制度记录进入林海：

- 更容易理解强制保存记忆造成的伤害；
- 可以证明人类社会中存在愿意终止献祭的人；
- 更倾向寻找可被社会接受的替代机制。

整体体验偏向：**从具体苦难追溯力量根源**。

### 7.2 先完成无名林海

玩家带着自然记忆循环的知识进入港口：

- 更容易识破“只有献祭才能保证安全”的制度谎言；
- 可以提出已经被世界规律验证的替代方案；
- 更容易说服部分人物，但也会威胁依赖记忆交易的利益集团。

整体体验偏向：**从世界真相审视人类制度**。

### 7.3 顺序差异的边界

顺序选择应改变：

- 可用对话论据；
- 部分非暴力解决方案；
- 人物初始态度；
- 资源消耗和风险；
- 个别场景反馈。

顺序选择不应导致：

- 无提示永久锁死主线；
- 只有唯一顺序才能获得合理结局；
- AI 临时创造不存在的关键道具或知识。

---

## 8. 第四地图：回声王庭

### 8.1 战役职责

回声王庭是所有记忆塔、征集制度和封印节点的中央控制地。前三张地图解决的是局部封印、社会后果和力量来源；回声王庭解决的是整套系统应当如何结束或继续。

### 8.2 进入条件

玩家必须完成：

- 灰烬塔的区域处理；
- 沉钟港的社会立场选择；
- 无名林海的起源调查。

“完成”不要求获得最佳结果，但相关代价必须被保留并带入最终地图。

### 8.3 最终判定来源

回声王庭根据三类成果开放不同方案：

| 来源地图 | 带入成果 | 决定的问题 |
| --- | --- | --- |
| 灰烬塔 | 封印状态、守忆人关系、余烬与侵蚀 | 玩家是否证明自己能处理局部黑焰 |
| 沉钟港 | 证词、公众支持、制度记录 | 改革是否获得人的承认与执行者 |
| 无名林海 | 替代原理、林海认可、自然路径 | 新体系是否符合世界规律 |

最终地图不能通过一次成功说服或一个隐藏按钮补齐缺失成果。

### 8.4 世界级结局方向

最终结局只在总体框架中定义方向，具体条件留待第四地图详细设计：

- **维持网络**：保留旧体系，以稳定为最高目标；
- **接管网络**：玩家或盟友成为新的中央管理者；
- **摧毁网络**：立即结束记忆献祭，同时承担秩序崩解风险；
- **重构网络**：同时需要事实、社会支持和替代规律；
- **碎片化自治**：终止中央控制，让各地区独立决定记忆制度。

## 9. 跨地图状态传递

建议战役层维护以下结构化状态：

```ts
type CampaignState = {
  towerOutcome: 'maintained' | 'released' | 'inherited' | 'reconstructed';
  archivistRelationship: number;
  emberState: number;
  echoCorruption: number;
  harborOutcome?: string;
  publicSupport?: number;
  testimonyCount: number;
  forestOutcome?: string;
  naturalSealKnowledge: boolean;
  forestRecognition: number;
  campaignPromises: string[];
  brokenPromises: string[];
};
```

具体字段可以在各地图细纲完成后调整，但必须遵守：

- 地图结局由规则层写入状态；
- 后续地图只读取已确认状态；
- AI 可以描述状态造成的后果，但不能自行改写状态；
- 关键状态必须通过 UI、人物反应或环境变化让玩家感知；
- 不使用隐藏的“善恶分数”替代具体选择与责任。

## 10. 战役主题递进

四张地图依次回答四个层级的问题：

1. **灰烬塔：发现牺牲。**
2. **沉钟港：看见牺牲如何制度化。**
3. **无名林海：理解牺牲并非唯一规律。**
4. **回声王庭：决定用什么制度取代旧制度。**

主题从个人遭遇逐步扩展：

```text
一座塔的异常
    ↓
一座城市的制度
    ↓
整个世界的自然规律
    ↓
文明应如何管理记忆
```

## 11. 战役宏观情绪节奏

| 地图 | 主导情绪 | 战役作用 |
| --- | --- | --- |
| 灰烬塔 | 神秘、压迫、道德觉醒 | 让玩家意识到问题存在 |
| 沉钟港 | 喧闹、愤怒、社会冲突 | 让玩家看见问题影响真实人群 |
| 无名林海 | 寂静、敬畏、反思 | 降低外部冲突，澄清世界真相 |
| 回声王庭 | 压迫、集结、抉择、余韵 | 汇总所有后果并决定世界方向 |

宏观节奏：

```text
局部神秘
  → 社会冲突扩大
  → 安静下潜与真相澄清
  → 世界级压力重新上升
  → 最终选择
  → 根据代价产生不同余韵
```

沉钟港与无名林海无论采用何种顺序，都应形成“外部冲突”与“内部反思”的节奏对照。

---

## 12. 全局设计约束

- 每张地图内部包含六个大场景，但不强制使用完全相同的场景节奏。
- 每张地图至少产生一个会进入最终地图的结构化成果。
- 地图之间传递的是事实、资源、关系和责任，不只是剧情摘要。
- 中期地图允许自由顺序，但任何顺序都必须能够完成主线。
- 完美结局不得依靠最终地图临时补齐前三张地图缺失的条件。
- 任一地图的重大选择都应在至少一张后续地图中产生可见反馈。
- 地图结局可以不理想，但不能让玩家在无预警情况下永久无法完成战役。
- 模型不可用时，四地图关系、开放条件和结局判定必须仍然有效。

---

## 13. 最终框架准则

> 四张地图不是四次独立冒险，而是同一制度从局部封印、社会后果、自然起源到中央权力的四层剖面。

玩家在回声王庭获得的最终选择，必须能够追溯到前三张地图中已经确认的事实、争取到的支持、保存或消耗的资源，以及愿意承担的责任。
